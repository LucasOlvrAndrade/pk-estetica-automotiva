PK ESTÉTICA AUTOMOTIVA — STACK E TODOS OS PROMPTS COM RESPOSTAS RESUMIDAS
Trabalho final de Desenvolvimento de Interfaces. Gerado a partir do PROMPTS.md.
==============================================================================

STACK DO PROJETO
------------------------------------------------------------------------------
Linguagens e base
  - HTML5 semântico (uma página, cada <section> é uma página do app via rotas por hash).
  - CSS3 puro: design tokens (variáveis), Grid, Flexbox, :has(), clip-path, background-clip: text,
    temas escuro ("Black Chrome") e claro ("Silver"), prefers-reduced-motion, forced-colors.
  - JavaScript moderno em módulos ES (import/export), um objeto por arquivo (padrão IIFE), sem
    framework de UI.

Ferramentas de build e execução
  - Node.js LTS + npm (gerenciador de pacotes).
  - Vite 8 (servidor de desenvolvimento, build otimizado na pasta dist/ e preview).

Bibliotecas (npm)
  - three 0.187 (Three.js): cena 3D da abertura — GLTFLoader, DRACOLoader (modelo comprimido),
    RoomEnvironment + PMREMGenerator (environment map dos reflexos), MeshPhysicalMaterial
    (verniz/clearcoat), EffectComposer + UnrealBloomPass + OutputPass (pós-processamento).
  - gsap 3 + ScrollTrigger: parallax ligado à rolagem (só desktop com mouse).
  - lenis 1: rolagem suave (só desktop com mouse).
  - @fontsource/saira-extra-condensed e @fontsource/manrope: fontes embutidas no build.

Dados e APIs
  - LocalStorage (chaves estetica:*) acessado só pelo módulo AppStorage; sessionStorage para
    preferências de tela (abertura vista, cache da FIPE).
  - API Tabela FIPE (parallelum): marcas, modelos e anos, com fetch + async/await, tempo limite de
    6 s (AbortController) e cache.
  - API ViaCEP: endereço do leva e traz.
  - APIs do navegador: Notification (aviso de "pronto"), Canvas 2D (carro do hero, compressão de
    fotos do check-in), WebGL (abertura 3D), IntersectionObserver, ResizeObserver, History API
    (rotas por hash), <dialog>.

Módulos do código (src/js)
  storage (AppStorage), servicos (Servicos), ui (UI), api (Api), veiculos (Veiculos),
  agenda (Agenda), checkin (Checkin), acompanhamento (Acompanhamento), fidelidade (Fidelidade),
  historico (Historico), carro3d (Carro3D, carro em Canvas 2D), modelo3d (Modelo3D, carrega o
  Civic 3D), intro3d (Intro3D, abertura), vitrine3d (Vitrine3D, carro 3D do Início),
  rotas (Rotas), movimento (Movimento), app (App) — ponto de entrada: src/main.js.

Recursos visuais
  - Modelo 3D: Honda Civic Type R (EK9) por marksform – Sketchfab (CC BY 4.0), comprimido com
    Draco + WebP via @gltf-transform/cli.
  - Logo PK (monograma) em SVG próprio; ícones lineares em SVG próprios.
  - Foto do comparador antes × depois fornecida pelo grupo (src/assets/imagens/polimento.webp).

Qualidade e testes
  - Validação W3C (validator.w3.org para HTML e jigsaw.w3.org para CSS): 0 erros.
  - axe-core 4.10 (acessibilidade WCAG 2.1 AA) em todas as páginas, nos dois temas.
  - Lighthouse (desempenho, acessibilidade e boas práticas).
  - Testes automatizados no Chrome headless via Chrome DevTools Protocol (jornada completa, rotas,
    diagnóstico com 768 combinações, abertura 2D e 3D, animações, dados antigos).

Hospedagem e versionamento
  - Vercel (CLI), domínio https://pkestetica.lucas-andrade.dev — publica só a pasta dist/.
  - GitHub (repositório público) para o código-fonte.
  - Editor: VS Code. IA: Claude Code (registro em PROMPTS.md).
